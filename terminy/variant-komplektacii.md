# Вариант комплектации

**Вариант комплектации** в УТ 11 объект, который описывает состав: для номенклатуры типа «Комплект» это разрез, по которому хранится набор комплектующих и их доли стоимости ([§ 2.1](../02-ut-komplekty.html), ut8doc/339). На практике у варианта две роли.

Роль честная: состав комплекта. Один комплект может иметь несколько вариантов (разные поставки, разная комплектация для разных каналов), при сборке «Сборка товаров» состав берётся из выбранного варианта [ИТС, § 2.1, § 2.3].

Роль обходная: вариант заводят для номенклатуры типа «Товар», чтобы получить у одного товара несколько сущностей с разными ценами, не заводя дубль карточки [ВЕБ, практика; в книге: [§ 1](../01-glavnaya-karta.html), [§ 7.1](../07-metodika-i-testy.html)]. Работает ровно в границах настройки «Варианты номенклатуры»: отчёты, складские остатки и обмен видят товар и вариант по-разному.

Место в нашей истории про обмен. Состав из варианта комплектации УТ не переезжает в спецификацию БП: строки конвертации «вариант → спецификация» в правилах нет ([§ 5.7](../05-perenos-dannyh.html#5.7)). Значит, сборку в УТ и спецификацию в БП ведут либо из одной мастер-базы, либо вручную дважды.
