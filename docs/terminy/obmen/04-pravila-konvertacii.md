# Правила конвертации: «маппинг» и «строка маппинга»

**Правила конвертации объектов (ПКО)** это файл настроек, который описывает переезд объектов из формата одной конфигурации в формат другой: какой объект какому объекту соответствует, какие поля куда кладутся, что проверять при загрузке и что делать при конфликте. Бывает «Отправка» (как собрать письмо из нашего объекта) и «Получение» (как из письма собрать наш объект). [ПЛАТФОРМА: общее из документации 1С, пояснение редактора]

**Маппинг** (от англ. to map, сопоставлять) разговорное название этих сопоставлений: «маппинг поля X» значит, в правилах есть строка «наше поле X → их поле Y». **Строка маппинга** буквально одна строка правил, один объект или одно поле.

Дальше следует главное следствие всей книги по теме комплектов: если в правилах нет строки для какого-то документа, этот документ не переедет никогда. Никакая настройка обмена, никакой флаг «выгружать складские документы» не помогут, потому что они включают вид документа в процесс, а как его превратить на той стороне, правилам неоткуда знать. Именно так устроена главная проблема переноса: «Сборка товаров» УТ имеет строку в правилах и превращается в «Комплектацию номенклатуры» БП ([§5.3](../../05-perenos-dannyh.html#5.3)), а «Разборка товаров» УТ и «Разукомплектация» БП строк не имеют, поэтому разукомплектация в БП руками ([§5.4](../../05-perenos-dannyh.html#5.4)). [ВЫВОД по правилам, подтверждённым цитатами в §5.3–5.4]

Где эти правила живут и можно ли их править. В типовой связке УТ 11 ↔ БП 3.0 правила лежат не отдельными файлами, а в модуле менеджера обмена («МенеджерОбменаЧерезУниверсальныйФормат») и в общих модулях формата [ВЕБ 2+, отчёт 09: практика патчей]. Правила можно перехватывать расширением: обработчик `&ИзменениеИКонтроль("ПКО_Справочник_Номенклатура_Отправка_ПриОтправкеДанных")` позволяет подправить или удалить (`#Удаление`) отдельные сопоставления без снятия конфигурации с поддержки [ВЕБ 2+, отчёт 09, декабрь 2024]. Это и есть легальный способ «починить маппинг»: не переписывать модуль, а надстроить расширение.
