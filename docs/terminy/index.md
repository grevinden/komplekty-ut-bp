# Словарь терминов

Здесь собраны все термины книги, которые не являются общеупотребительными словами. Правило такое: встретили незнакомое слово, открыли его статью, вернулись в главу. Статьи пишутся человеческим языком и для новичка, и для бухгалтера.

Важно о статусе текста: пояснения в статьях составляет редактор книги, это не цитаты. Цитаты ИТС и веб-находки внутри статей помечены как обычно: [ИТС], [ВЕБ 1], [ВЕБ 2+], [ВЫВОД], [НЕ ПОДТВЕРЖДЕНО].
