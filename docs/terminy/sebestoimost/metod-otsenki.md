# Метод оценки (средняя, ФИФО)

**Метод оценки** правило, по какой цене списывать со склада единицу товара при выбытии (продаже, передаче в производство, сборке комплекта). Партия партии рознь: купили три раза по трём ценам, а списывать надо по чему-то одному. [ПЛАТФОРМА, пояснение редактора]

Бухгалтерский учёт ограничивает выбор: по ФСБУ 5/2019 при выбытии запаса по каждому виду разрешены способ «по каждой единице» или «средняя первоначальная стоимость» [ВЕБ 2+, net/06, со ссылкой на п. 24 стандарта]. Способ «по единице» работает только для уникальных дорогих позиций; складской поток оценивают средней. В налоговой учётной практике применяется средний метод по группе однородных запасов [ВЕБ 2+, net/06]. В 1С исторически доступен и ФИФО (first in, first out: списывается по ценам самых ранних партий); в связке УТ ↔ БП методики баз могут различаться, из-за этого цифры «разъезжаются» законно [net/06, § 6.3].

Два факта, важных для нашей темы.

Метод оценки не зависит от партионного учёта. Включённая в БП КОРП функциональность «партионный учёт» меняет запись движений (в аналитике появляется конкретная партия поступления), но цену выбытия база считает тем же методом из учётной политики [ВЕБ 2+, net/06, проверка в § 6.5]. Поэтому «включим партии и узнаем цену каждой штуки» не работает.

Комплект наследует проблему дважды. При сборке себестоимость комплекта собирается из себестоимостей комплектующих, рассчитанных по методу. При разукомплектации эта стоимость раскладывается обратно по долям, а не по исходным партиям, потому что связь «комплект ↔ партии его комплектующих» в модели не хранится [ВЫВОД, § 6.5].
