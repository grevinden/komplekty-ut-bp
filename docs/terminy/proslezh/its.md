# ИТС

**ИТС** информационно-технологическое сопровождение договор с фирмой «1С» на подписку: доступ к базе знаний its.1c.ru (документация конфигураций «как настроено», статьи, методички) и к линии консультации (Горячая линия, Гарантия) [ВЕБ 1+, общедоступное описание сервиса].

Для этого проекта ИТС источник всех подтверждённых цитат о механике УТ и БП. Координата вида `ut115doc/798` в тексте книги читается так: `ut115doc` база документации «Управление торговлей 11» в поиске ИТС, `798` номер документа в этой базе. Список всех использованных координат — §8.1, дословные выжимки — [файл EVIDENCE-2026-10-30.md](https://github.com/grevinden/komplekty-ut-bp/blob/main/its/EVIDENCE-2026-10-30.md).

Две границы, о которых честно сказано в книге:

* релиз-листы и точные изменения механизмов по версиям публикуются только в ИТС и 1С:ЛМС, поэтому «что изменилось в 11.5.22 по сравнению с 11.5.21» из открытого веба непроверяемо [§9.6], [§9.7];
* проводки Дт/Кт ИТС не публикует нигде, поэтому §4.5 реконструкция сообщества, а не цитата [§4.5].
