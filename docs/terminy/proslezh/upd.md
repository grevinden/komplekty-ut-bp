# УПД

**УПД** универсальный передаточный документ: один файл закрывает и передачу товара (функция «передаточный документ»), и налоговую часть (функция «счёт-фактура»), либо что-то одно. Формат электронного УПД утверждён ФНС (приказ ЕД-7-26/970@ и последующие, версия формата 5.03) [ВЕБ 2+, net/05].

Зачем в нашей теме. УПД это лицо отгрузки для контрагента, и комплекты здесь видны во всей красе:

* если УТ разворачивает набор в комплектующие, в УПД едут строки комплектующих; если нет одна строка «набор» [§3.3](../../03-ut-nabory.html), [§9.7](../../09-prilozhenie-web.html#9.7);
* расхождение «УТ считает это набором, БП комплектующими» становится видимым покупателю именно в УПД [ВЫВОД; вопрос оператору №5, §9.5];
* для прослеживаемых товаров каждая строка УПД тащит блок сведений прослеживаемости (ГТД, РНПТ, код товара) см. [«подстрока»](podstroka.html).
