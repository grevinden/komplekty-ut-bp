# «Подстрока» УПД

**«Подстрока»** разговорный термин из писем ФНС: формально в УПД одна строка товара (`СведТов`), но для прослеживаемого товара к ней прикладывается повторяющийся блок `СведПрослеж` по числу партий/деклараций. В XML-формате (приказ ФНС ЕД-7-26/970@, версия 5.03) это `maxOccurs="unbounded"` одного элемента внутри строки, а не отдельные строки таблицы [ВЕБ 1+, отчёт 05: разбор XML-формата].

Почему это важно комплектам. Одна строка отгрузки может нести несколько «подстрок» прослеживаемости. Логичный вопрос практика: если комплект собран из нескольких прослеживаемых компонентов, сколько подстрок должно быть в строке «Комплект» и чьи ГТД/РНПТ в них стоять? Официального ответа «для комплектов» в письмах нет; вердикт отчёта 05: сборка комплекта не прекращает прослеживаемость, поэтому подстроки обязаны доехать до покупателя [ВЫВОД по §6.1]. На стороне БП для этого предусмотрен вид номенклатуры «Прослеживаемый товар(ы) в составе комплекта» [ВЕБ 2+].

Проверка на живой базе: сформировать УПД на отгрузку собранного прослеживаемого комплекта и посмотреть XML/печатную форму число блоков прослеживаемости в строке (§7.3).
