# ГТД

**ГТД** грузовая таможенная декларация: документ, по которому импортный товар прошёл таможню. В учёте 1С «ГТД» реквизит строки поступления и складских регистров: партия импортного товара carries свою декларацию, она же попадает в печатные документы отгрузки [ВЕБ/практика, §6.1].

Почему ГТД касается комплектов. В УТ при учете по ГТД каждая строка сборки/отгрузки хочет знать декларацию. Для комплекта декларация у комплектующих своя, и УТ подставляет ГТД от «основной» комплектующей ([§6.1](../../06-skvoznye-temy.html), [ВЕБ: [Кодерлайн, 17.11.2021](https://erpguide.ru/blog/sborka-iz-komplektuyushhih-v-1s-erp-upravlenie-predpriyatiem-2-5-1s-upravlenie-torgovlej-2-5-1s-kompleksnaya-avtomatizacziya-2-5/) — «Укажите основную комплектующую, страна и ГТД которой распространится на весь комплект»]). На стороне БП ГТД ждёт из документа поступления, а не из сборки: расхождение всплывает при печати УПД ([§9.4](../../09-prilozhenie-web.html#9.4)).

Проверка на живой базе: распечатать УПД на отгрузку собранного комплекта и сверить ГТД в строках с декларациями комплектующих (§6.1, тест из чек-листа §7.3).
