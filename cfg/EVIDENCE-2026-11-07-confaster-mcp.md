только `shcntx`.

## Что изменилось в port.7 (главное)

1. **Справка языка запросов теперь индексируется.** После переиндексации `help.db` даёт
   25 550 тем вместо 25 520, и в `category`, кроме `syntax` (25 520), появились
   `query` = **25 тем** и `language` = **5 тем** — раньше было 0 и 0. Это те самые
   методические темы из `shquery_ru.hbk`/`shlang_ru.hbk`: «Операция выбора в языке запросов»
   (`query/query_select`), «Расчет итогов запроса», «Условия в языке запросов»,
   «Приведение типа», «Упорядочивание по иерархии», «Арифметические операции» (`language/…`)
   и т. д. `get_1c_help_topic('8.3.27.2342/query/query_select')` отдаёт полный текст
   (`ВЫБОР … КОГДА … ТОГДА … ИНАЧЕ … КОНЕЦ`).
2. **У `search_1c_help` появился параметр `category`** (`syntax`|`query`|`language`|`all`).
   `category:"query"` + «Псевдоним» → «Псевдонимы источников данных», «Псевдоним поля
   выборки»; `category:"language"` + «логические» → «Логические операции». Без параметра
   ищутся все разделы.
3. **Новые параметры у инструментов кода:** `find_symbol(exact)`, `search_code(regex, scope,
   configuration)`, `semantic_find(context_objects, include_code)`,
   `get_module_functions(configuration, limit)`, `get_object_structure/configuration`,
   `get_file_context(configuration)` — все проверены, работают.
   `get_object_structure` теперь принимает имя **без префикса** (`ЗаказКлиента` → находится)
   и отдаёт поле `extensions[]` с `adopted`/`added_attributes` по каждому расширению.
4. **`switch_export_root` идемпотентен:** повторный вызов с теми же корнями →
   `{"status":"unchanged","message":"Уже подключен к этой папке"}`.

## Что осталось как было

- Инкрементальный `sync_index` на обоих серверах: `{"added":0,…,"message":"Индекс актуален,
  изменений не найдено"}` за ~1 с (полные индексы port.6 сохранены: 49 627 / 86 827 файлов).
- **Полная ссылка на язык запросов (глава 8) по-прежнему НЕ индексируется.** Тем `query`
  всего 25 и это методические заметки, а не справочник операторов: запрос `ВЫБРАТЬ`/`ПОМЕСТИТЬ`/
  `СОЕДИНЕНИЕ` в `help.db` по заголовку = 0, в `search_1c_help` дают мусор объектной модели
  («СтандартнаяКомандаПоляВвода.Выбрать»). Частные имена операторов (`РАЗРЕШЕННЫЕ`,
  `ОСТАТКИИОБОРОТЫ` как виртуальная таблица) — 0. Для синтаксиса запроса по-прежнему —
  навык `zapros-1c` (глава 8 документации 8.3.27) или `1c-platform-docs`.
