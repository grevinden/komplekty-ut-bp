# Протокол: сборка готовых .cfe и раунд-трип-проверка (05.11.2026)

Момент прогона: 05.11.2026, платформа 8.3.27.2342, `ibcmd`
(`/opt/1cv8/x86_64/8.3.27.2342/ibcmd`). Копии стенда: `/tmp/opencode/exch/bp`
(БП 3.0.208.14, без учётки) и `/tmp/opencode/exch/ut` (УТ 11.5.22.186,
аутентификация — `--user="Администратор"`). Оба расширения к этому моменту
установлены и активны в копиях (протокол
`EVIDENCE-2026-11-05-ext-install.md`).

## 1. Что собрали

Артефакты в репозитории: `tools/1c/ext/dist/`

| Файл | Размер | Источник |
|---|---|---|
| `КомплектыОбмен.cfe` | 27 247 б | копия `bp` |
| `КомплектыБП.cfe` | 20 922 б | копия `bp` |
| `КомплектыУТ.cfe` | 9 466 б | копия `ut` |

Команда сборки (содержимое расширения берётся из **базы**, поэтому сборка
 возможна только когда расширение уже установлено из XML-исходников):

```bash
ibcmd config save --db --db-path=/tmp/opencode/exch/bp \
  -e КомплектыОбмен tools/1c/ext/dist/КомплектыОбмен.cfe
# то же для КомплектыБП; для КомплектыУТ — --db-path=/tmp/opencode/exch/ut
# и --user="Администратор"
```

`ibcmd config save` единственный из режимов config, принимающий `--db`
(собрать из БД). `config load` работает только с дизайн-копией (`--db-path`).

## 2. Раунд-трип-валидация

Каждый .cfe загружен обратно в ту же копию и проверен метаданные-валидатором:

```bash
ibcmd config load --db-path=/tmp/opencode/exch/bp \
  -e КомплектыОбмен tools/1c/ext/dist/КомплектыОбмен.cfe --force
ibcmd config check --db-path=/tmp/opencode/exch/bp -e КомплектыОбмен
```

Результат для всех трёх файлов (для ut — с `--user="Администратор"`):

- load: `Configuration loading completed successfully`;
- check: `Metadata validation completed` (без ошибок).

То есть собранные .cfe самодостаточны: их можно ставить в чистую базу из
файла, исходники XML для установки не нужны.

## 3. Замечания

- Режим `config apply -e <Расш> --force` (обновление уже подключённого
  расширения) — альтернативный путь доставки, проверен ранее
  (`EVIDENCE-2026-11-05-ext-install.md`); `load` поверх активной копии тоже
  проходит, если база доступна (сеансы 1С закрыты).
- Внутри .cfe — тот же состав, что в XML-исходниках `tools/1c/ext/*`:
  заимствованные объекты с аддитивными модулями расширения, XDTO-пакет
  `КомплектыОбмен_EnterpriseData` (namespace
  `http://v8.1c.ru/edi/edi_stnd_ext_enterprisedata/EnterpriseData/1.20`).
