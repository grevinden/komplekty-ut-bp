# Комплекты и наборы в УТ 11.5 и БП 3.0

Проект исследования: как устроены комплекты/наборы в «Управлении торговлей» 11.5
и «Комплектации номенклатуры» в БП 3.0 КОРП, и что ломается при переносе УТ → БП.

## Публикация (GitHub Pages)

Издание опубликовано отдельным чистым репозиторием: **https://github.com/grevinden/komplekty-ut-bp**
(сайт собирается штатным Jekyll из корня ветки `main`).

Мастер-копия учебника — каталог [`docs/`](docs/index.md) этого проекта. Порядок правки:
редактируете `docs/**/*.md`, затем `./publish-site.sh "комментарий"` — скрипт синхронизирует
`docs/` с репозиторием сайта и пушит; через минуту Pages обновится.
Каждая страница начинается с YAML-шапки (`layout`, `title`) — Jekyll по ней превращает `.md`
в HTML-страницу; ссылки между страницами ведут на `.html`-имена.

## Что где лежит

- `docs/` — опубликованное издание: обложка-оглавление (`index.md`), главы 01–09,
  словарь терминов `terminy/`.
- `net/01`–`net/09` — отчёты поисковых фронтов (рабочие материалы, на сайт не входят).
- `its/EVIDENCE-2026-10-30.md` — цитаты ИТС с координатами.
- `RESEARCH-plan.md`, `AGENTS.md` — план исследования и правила работы.

`.handoff/` в репозиторий не попадает (в нём ключи доступа ИТС), см. `.gitignore`.
