# Комплекты и наборы в УТ 11.5 и БП 3.0

Учебник: как устроены комплекты и динамические наборы в «Управлении торговлей» 11.5,
«Комплектация номенклатуры» в БП 3.0 КОРП — и что ломается при переносе данных УТ → БП.

Начинать с оглавления: **[index.md](index.md)** ·
онлайн: https://grevinden.github.io/komplekty-ut-bp/

Каждая страница — отдельный Markdown-файл с YAML-шапкой (`layout`, `title`);
сборку делает штатный Jekyll GitHub Pages из корня ветки `main`.
Ссылки между страницами — относительные, на `.html`-имена.

Метод изложения: каждая нетривиальная фраза подтверждена цитатой из ИТС
(координата вида `ut8doc/339`), неподтверждённое помечено **[ВЫВОД]** или
**[НЕ ПОДТВЕРЖДЕНО]**, находки форумов — **[ВЕБ 1]** / **[ВЕБ 2+]**.
