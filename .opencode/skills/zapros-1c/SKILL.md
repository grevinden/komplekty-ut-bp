## Каркас запроса

```
<Описание запроса>            — единственная обязательная секция
[ОБЪЕДИНИТЬ …]               — объединение запросов
[УПОРЯДОЧИТЬ ПО …]
[АВТОУПОРЯДОЧИВАНИЕ]
[ИТОГИ … ПО …]
[ИНДЕКСИРОВАНИЕ ВРЕМЕННОЙ ТАБЛИЦЫ …]
```

```
ВЫБРАТЬ [РАЗРЕШЕННЫЕ] [РАЗЛИЧНЫЕ] <поля с КАК/Псевдоним>,
ИЗ <таблица> [КАК алиас] [[ВНУТРЕННЕЕ|ЛЕВОЕ|ПРАВОЕ|ПОЛНОЕ] [ВНЕШНЕЕ] СОЕДИНЕНИЕ … ПО <условие>]
ГДЕ <условие>
СГРУППИРОВАТЬ ПО <неагрегированные поля>
ИМЕЮЩИЕ <условие с агрегатной функцией>
УПОРЯДОЧИТЬ ПО <поле|выражение|псевдоним> [ВОЗР|УБЫ] [ИЕРАРХИЯ]
```

Приоритет логических операторов: `НЕ` → `И` → `ИЛИ`; скобки переопределяют.

## Правила, на которых я уже обжигался (проверено на базах проекта)

- **`LIKE` в 1С нет — есть `ПОДОБНО`** (регистр игнорируется, спецсимволы
  `%`, `_`, `[abc]`, `[^abc]`; литерал своего спецсимвола — `СПЕЦСИМВОЛ '\'`).
  [БАЗА + 8.4.18.8]
- **В виртуальной таблице нельзя разворачивать ссылку**:
  `Вирт.Номенклатура.Наименование` — синтаксическая ошибка даже в ВЫБРАТЬ.
  Соединяйся со `Справочник.Номенклатура КАК Ном ПО Ном.Ссылка = Вирт.Номенклатура`
  и бери `Ном.Наименование`. У обычных таблиц разворачивание разрешено. [БАЗА]
- **Литералы — только в двойных кавычках** (`"Диана"`); одинарные — ошибка. [БАЗА]
- Виртуальные таблицы **всегда с круглыми скобками**, даже пустыми:
  `РегистрНакопления.ТоварыОрганизаций.Остатки(, )` — иначе
  `VirtualTableCallWithoutParameters`. В УТ 11.5 у `ТоварыОрганизаций`
  есть только `Остатки`, других виртуальных таблиц нет. [БАЗА]
- **Фильтр тащи внутрь виртуальной таблицы** (2-й параметр), период — в 1-й
  параметр `{НачПериод, КонПериод}`: это отбор ДО агрегации, быстрее ГДЕ.
- `bsl-language-server` на конкатенированных BSL-запросах (`"ВЫБРАТЬ …" + …`)
  даёт **ложные** `QueryParseError` — реальную проверку делает только платформа. [БАЗА]
- Результат сравнения с `NULL` = `NULL` → в ГДЕ/ИМЕЮЩИЕ/КОГДА условие
  считается **не выполненным**. Для «равно NULL» — `ЕСТЬ NULL`; для
  «NULL как 0» — `ЕСТЬNULL(Поле, 0)`. [8.4.18.3]
- Сравнение строк в запросе **не учитывает регистр и концевые пробелы**
  («bb» = «bb » — Истина, в отличие от BSL). Поля неограниченной длины
  (Строка 0, ХранилищеЗначения, ТипЗначения) сравнивать нельзя. [8.4.18.3]

## Быстрые шпаргалки

Условие отбора (8.4.18): `= <> > < >= <=`, `В (список|подзапрос)`,
`В ИЕРАРХИИ(&Группа)`, `(а,б) В (&ТаблицаЗначений)` — первые N колонок ТЗ;
`НЕ В` с подзапросом и NULL → ложь; `МЕЖДУ` — границы включительно;
`ЕСТЬ [НЕ] NULL`; `ССЫЛКА Справочник.Контрагенты` — проверка типа ссылки;
`[НЕ] ПОДОБНО '%Шаблон%' [СПЕЦСИМВОЛ '\']`. Из подзапроса `В` видно поля
таблиц внешнего запроса, встречавшихся левее (коррелированный подзапрос).

Функции (8.4.17, headings 8.4.17.4.1–38): `ЕСТЬNULL(выр, запас)`,
`ВЫБОР КОГДА…ТОГДА…ИНАЧЕ КОНЕЦ`, `ВЫРАЗИТЬ(выр КАК Число(10,2))` —
расширить тип колонки, `Значение(Перечисление.Вид.Значение)` — литерал
ссылки в тексте запроса, `ПРЕДСТАВЛЕНИЕ(Ссылка)`, `АВТОНОМЕРЗАПИСИ()`,
`УНИКАЛЬНЫЙИДЕНТИФИКАТОР()`, `ТИПЗНАЧЕНИЯ(выр)`, `СГРУППИРОВАНОПО()`.
Строки: `ПОДСТРОКА`, `ДЛИНАСТРОКИ`, `ЛЕВ`, `ПРАВ`, `СОКРЛ|СОКРЛП|СОКРП`,
`СТРЗАМЕНИТЬ`, `СТРНАЙТИ`, `СТРОКА()`, регулярки `ВРЕГ(шаблон, стр)` /
`НРЕГ` (регистронезависимая / чувствительная). Даты:
`НАЧАЛОПЕРИОДА(Д, МИНУТА|ЧАС|ДЕНЬ|НЕДЕЛЯ|МЕСЯЦ|КВАРТАЛ|ГОД)` и
`КОНЕЦПЕРИОДА` (второй параметр — ключевое слово периода без кавычек!), `ДАТАВРЕМЯ(г,м,д…)`,
`ДОБАВИТЬКДАТЕ(Д, МЕСЯЦ, -1)`, `РАЗНОСТЬДАТ(а, б, ДЕНЬ)`,
`ГОД МЕСЯЦ ДЕНЬ ЧАС МИНУТА СЕКУНДА НЕДЕЛЯ КВАРТАЛ ДЕНЬНЕДЕЛИ ДЕНЬГОДА`.
Числа: `ОКР`, `ЦЕЛ`, алгебраические, тригонометрические.
Агрегатные (8.4.12): `СУММА`, `СРЕДНЕЕ`, `МИНИМУМ`, `МАКСИМУМ`,
`КОЛИЧЕСТВО(* | РАЗЛИЧНЫЕ выражение)` — «различных» отдельной функции нет.

Виртуальные таблицы (8.2; имена и параметры — вне этой главы, подтверждены
на базах проекта [БАЗА]): регистры сведений — `СрезПервых`, `СрезПоследних`
`(Период, Условие [, Упорядочивание, Измерения])`, `СрезСданных(&Узел)`;
накопления — `Остатки(Период, Условие)`, `Обороты(Период, Активность,
Условие, Выражения, ИтогПо)`, `ОстаткиИОбороты(Период, Активность, Условие,
Выражения, ИтогПо)` — в примере главы `ОстаткиИОбороты(, , Авто, , )`;
бухгалтерии/расчётов — `Движения(Период, Условие)`; планы обмена —
`Изменения(&Узел)`. Пустой параметр = без ограничения; период — `{Нач, Кон}`.
Вирт. таблицы обычных полей не имеют — см. ловушку про разворачивание выше.

Итоги (8.4.13): `ИТОГИ СУММА(Сумма) ПО ОБЩИЕ, Уровень1.Уровень2 [, …]`;
`ПО … ИЕРАРХИЯ` — иерархические итоги по полю-ссылке на иерарх.справочник;
`ПО Период ПЕРИОДАМИ(МИНУТА, ДАТАВРЕМЯ(…), ДАТАВРЕМЯ(…))` — итоги
периодами. Контрольные точки — из полей/псевдонимов ВЫБРАТЬ. Обход — BSL ниже.

Временная таблица (8.4.10): `ВЫБРАТЬ … ПОМЕСТИТЬ ИмяТаблицы ИЗ …` —
`ПОМЕСТИТЬ` сразу после списка выборки; имя — как переменная BSL;
`УНИЧТОЖИТЬ ИмяТаблицы;` — удалить (ошибка, если таблицы нет);
`ДОБАВИТЬ ИмяТаблицы` — догрузка при совпадении структур, у последнего
поля перед `ДОБАВИТЬ` обязателен псевдоним, иначе слово съестся как псевдоним;
`ИНДЕКСИРОВАТЬ ПО` / `ИНДЕКСИРОВАТЬ ПО НАБОРАМ ((а,б), (в) УНИКАЛЬНО)` —
только в запросе ПОМЕСТИТЬ, поля — из списка выборки; типы колонок задаются
неявно (разрядность/длина — расширять через `ВЫБОР`/`ВЫРАЗИТЬ`);
`ИЗ &ВнешнийИсточник КАК Источник` — ВТ из таблицы значений / ТЧ /
результата запроса (у ТЗ явные типы; соединения для внешнего источника
нельзя); `ДЛЯ ИЗМЕНЕНИЯ` — блокировка от других транзакций.
Пакет: запросы через `;`, выполняются по порядку (8.4.7.4); `/////…` —
комментарий-разделитель; `УПОРЯДОЧИТЬ`/`ИТОГИ` держи на последнем
(результативном) запросе пакета; модная конвенция `; ЗАВЕРШИТЬ` в этой
главе не описана [ВЕБ/конвенция].

## Работа в BSL (8.5)

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ
  | Номенклатура.Наименование КАК Наименование,
  | Номенклатура.Родитель.Наименование КАК Родитель
  |ИЗ
  | Справочник.Номенклатура КАК Номенклатура
  |ГДЕ
  | Номенклатура.Ссылка В ИЕРАРХИИ(&Группа)
  |ИТОГИ
  | МАКСИМУМ(Наименование)
  |ПО
  | ОБЩИЕ";
Запрос.УстановитьПараметр("Группа", Группа);
Результат = Запрос.Выполнить();
Если Результат.ЭтоПустой() Тогда … КонецЕсли;   // метод платформы, вне главы
Выборка = Результат.Выбрать();                         // линейно
// Выборка = Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);
// Выборка = Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкамСИерархией);
Пока Выборка.Следующий() Цикл
  Сообщить(Выборка.Наименование);
  // вложенная выборка: Выборка.Выбрать(способ, Выборка.Группировка())
КонецЦикла;
ТЗ = Результат.Выгрузить();                            // таблица значений
```

- Результат пакета (`Выполнить()`) — результат **последнего результативного**
  запроса (создающего/изменяющего/удаляющего ВТ); без таких — последнего
  запроса. `ВыполнитьПакет()` → массив всех результатов;
  `ВыполнитьПакетСПромежуточнымиДанными()` → с содержимым ВТ (отладка).
- Типы колонок результата всегда включают NULL.
- Обход групп: `СледующийПоЗначениюПоля("Поле")`, `НайтиСледующий(Значения)`;
  тип текущей строки итогов: `Уровень()`, `ТипЗаписи()`, `Группировка()`.
- Временные таблицы между запросами: один `Новый МенеджерВременныхТаблиц`
  присвоить `Запрос.МенеджерВременныхТаблиц` в запросе создания и в
  использующем; после `Выполнить()` содержимое доступно через
  `Запрос.МенеджерВременныхТаблиц.Таблицы["Имя"].ПолучитьДанные()`.
  `Менеджер.Закрыть()` чистит всё; при откате транзакции ВТ теряются.
- Пакетная выборка полей объектов (`Запрос.ПакетныеОбъекты`) — ускоряет
  обращение к `.Ссылка.Поле` в обходе; вне главы 8, но на 8.3.27 работает.
- Программная сборка/правка текста: `Новый СхемаЗапроса` →
  `УстановитьТекстЗапроса()/ПолучитьТекстЗапроса()`; интерактивно из
  рантайма — `КонструкторЗапроса.Показать(Обработчик)`.

## Приём проверки перед прогоном на базе

1. Написал запрос → `bsl-language-server analyze` (ложные QueryParseError на
   конкатенациях игнорируем, реальные — синтаксис BSL).
2. Сомнительный фрагмент — грепом в `reference-glava-8.md` по разделу выше.
3. Боевая проверка — платформа (`/Execute` обработкой с `Сообщить`/файлом,
   см. навык `v8-diag-run`): только она знает метаданные базы.
